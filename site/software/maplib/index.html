maplib

Also known as: maplib RDF

Software Technology & Web RDF Data Mapping / ETL

High-performance Python/Rust framework for constructing and querying RDF knowledge graphs from tabular data using OTTR templates, with Polars/Apache Arrow integration, SPARQL, RDFS reasoning, SHACL validation, and Datalog support.
