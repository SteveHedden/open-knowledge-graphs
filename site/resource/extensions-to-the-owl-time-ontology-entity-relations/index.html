Extensions to the OWL-Time Ontology - entity relations

Also known as: vocab-owl-time-rel

Ontology General / Cross-domain

This note adds four new relations: time:equals, time:hasInside, time:disjoint and time:notDisjoint which complement the original relations and allow for description of more relationships between temporal entities.
